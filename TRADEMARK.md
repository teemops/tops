# Trademark Policy

The TOPS **software** is free. The TOPS **name** is not the same thing, and this page
explains the difference.

## The short version

- **The code is yours to use**, under [Apache License 2.0](LICENSE) — run it, modify it,
  fork it, sell services around it, deploy it commercially. No limits, no usage caps, no
  registration, no phoning home.
- **The names "TeemOps" and "TOPS" and the logos are not covered by that licence.** Use
  them to refer to this project accurately. Don't use them to name your own fork or
  product, or in a way that suggests we built, endorse, or support something we don't.

This is deliberate, and it's the only thing we hold back. It's how an open-source project
stays open while still meaning something when someone says "we run TOPS".

## What you can do without asking

- Say your product "works with TOPS", "integrates with TOPS", or "is based on TOPS"
- Write about TOPS — tutorials, reviews, comparisons, talks, criticism
- Use the name in a fork's documentation to describe where the code came from
  ("a fork of TOPS")
- Redistribute TOPS unmodified, keeping the name
- Run it commercially, for yourself or for clients, and charge for that

## What needs a different name

- **A modified distribution.** If you change the code and ship it to others, call it
  something else. "TOPS" should mean the thing we publish, so that users know what
  they're getting. This is the same principle Mozilla applies to Firefox and Red Hat
  applies to RHEL rebuilds — the code is free to rebuild, the brand isn't free to reuse.
- **A hosted service named after us.** Running TOPS as a service for others is fine and
  explicitly allowed. Calling it "TOPS Cloud", "Managed TOPS", or similar is not, because
  users would reasonably assume we operate it.
- **Your company, product, or domain name.** Don't register `tops-something.com` or ship
  "TOPS Pro".

## What we will never do

We won't use trademark to restrict the software. You will never need permission, a
licence key, or a subscription to run TOPS at any scale, modified or not. If you fork it
and rename it, that fork is legitimate and we won't come after it.

## Asking

Unsure, or want to use the name in a way not covered here? Open an issue. We'd rather say
yes to something reasonable than have people guess.
